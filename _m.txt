add bitwise operators and a batch of often-missing helpers

- Bitwise: BitwiseAnd / BitwiseOr / BitwiseXor / LeftShift / RightShift for every
  integer width plus bool (bool behaves as logical). Floats and complex are
  rejected like NumPy's TypeError; an out-of-range or negative shift count yields
  0, matching NumPy 2.x, and signed right shift stays arithmetic.
- Tools: Rot90 (any k, arbitrary axis pair), Average (weighted, per-axis or
  full-shape weights), PtP, LogSpace, GeomSpace, NanProd (all-NaN line -> 1),
  NanCumsum (NaN treated as 0), Kron (1-D/2-D, typed kernels), Slogdet.
- Reference cases: 15 new NumPy-compared cases (492 cases / 499 subtests total);
  logspace/geomspace stay unit-tested because the harness requires an array input.
- WASM: the five bitwise operators are exposed through the binary dispatcher.
- Coverage: new code dropped the gate to 84.5%; added dtype/edge tests for every
  kernel and error path, back to 85.5%.

Verification: gofmt clean, go vet 0, four packages pass, 499 subtests green,
coverage 85.5%, wasm rebuilt and the Node smoke test passes.
